- A background task's scratch folder that cannot be removed (for example read-only folders a build left behind) is now retried after 1 s, then with doubling waits up to 5 minutes, instead of on every watchdog pass; the scratch-cleanup worker sleeps while it has nothing queued.
- The persisted background-task sweep no longer rereads unchanged running tasks whose process is alive, or finished tasks whose scratch removal is still in progress, on every pass; it checks the process or the removal instead and reads the task again once either ends.
- A project's file watcher no longer stays busy, and no longer stops reading file events, while nothing drains its dispatch queue (for example a worktree with no bound session): it holds the changes, merged into one batch, and hands them on once the queue has room; past 16,384 held paths it requests a rescan, logged as `watcher overflow: reason=buffer_overflow`.
