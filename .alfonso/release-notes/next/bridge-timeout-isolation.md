- A tool call that times out on the standalone bridge now fails on its own, instead of restarting the shared AFT process and failing other sessions' calls. AFT restarts only when it has gone silent, and a read, outline, zoom, grep, glob, search, callgraph or inspect cut off by that restart is retried once. The `bridge.hang_threshold` setting no longer does anything; `doctor --fix` removes it. Thanks @null-axiom (#646).
