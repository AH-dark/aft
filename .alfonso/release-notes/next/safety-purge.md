- `aft_safety` has a new `purge` op that permanently deletes the calling session's undo backups and checkpoint copies of a file or of everything under a directory (up to the project root), so an agent can remove a secret it wrote or deleted by mistake. It asks the same edit permission a write to that path would, prunes the purged files from the session's checkpoints (dropping any checkpoint left empty and naming it in the reply), never touches other sessions, and cannot be undone (#603).
