Projects binding concurrently on macOS no longer intermittently lose their cache key and trigram index with `cache_dir_unavailable`. A Darwin race can report a missing file when another project has just created the shared coordination file. AFT now reopens it through the same pinned directory, with bounded retries and unchanged symlink protections. If coordination remains busy, the project still binds with a `cache_dir_busy` degradation and one automatic retry, instead of reporting an unavailable cache folder or requiring a rebind to recover its indexes.
