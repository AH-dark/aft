Projects binding concurrently on macOS no longer intermittently lose their cache key and trigram index with `cache_dir_unavailable`. A Darwin race can report a missing file when another project has just created the shared coordination file. AFT now makes a bounded sequence of attempts to open the shared coordination file, retaining the existing symlink protections. If coordination remains busy, the project still binds with a `cache_dir_busy` degradation and automatic retries with bounded backoff while the project remains bound, instead of reporting an unavailable cache folder or requiring a rebind to recover its indexes.
