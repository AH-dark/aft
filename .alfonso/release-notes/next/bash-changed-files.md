- Bash can optionally report project files observed changing during a command. Set user `bash.changed_files` to `list` or `diff` (default `off`); diffs use the starting Git blob for clean tracked text files with bounded output, and a bounded watcher flush includes last-moment writes without routine caveats. Actual overflow or a flush timeout is explicitly disclosed. Background commands report in their completion notice. Projects can turn the feature off but cannot enable it.
