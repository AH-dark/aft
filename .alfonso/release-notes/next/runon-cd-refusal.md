- `runon` refuses literal top-level `cd` and `pushd` targets that refer to local home content or another local Git checkout outside the copied checkout and declared siblings. The distinct `runon_cd_outside_checkout` refusal occurs before submission, with nothing run locally or remotely. Linux accepts declared siblings, including their aliases beside linked worktrees, and system paths such as `/tmp`. Windows targets also refuse literal absolute directory paths because the runner does not translate paths inside command strings; relative paths into the checkout or declared siblings remain allowed. Set the bash tool's `workdir` instead. Dynamic targets and directory changes inside subshells are unchanged.
