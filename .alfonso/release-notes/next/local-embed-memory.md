- Local semantic indexing now releases temporary ONNX Runtime CPU memory after each inference instead of retaining the largest attention allocation. All roots share one build/refresh session and a separate query session, so searches do not queue behind indexing batches. Queries reuse their small buffers and run without indexing-sized thread pools. Idle build sessions unload and reload on demand; root model leases keep the query session warm until unbind or eviction. The memory census reports live embedding sessions and estimated model bytes.
